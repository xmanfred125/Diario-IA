# Diario IA

Diario digital público de noticias de inteligencia artificial, en español.

Cada mañana se publica una nueva edición con las noticias de IA del día anterior:
nuevos modelos, anuncios, actualizaciones de plataformas y avances de empresas y
laboratorios de EE. UU., China y Europa.

- Portada con la última edición y tarjetas expandibles por noticia.
- Buscador por texto entre ediciones.
- Archivo navegable por fecha.

Las ediciones viven en `editions/` como archivos JSON (`YYYY-MM-DD.json`), con un
manifiesto en `editions/index.json`. El sitio es 100% estático y se publica con
GitHub Pages.
